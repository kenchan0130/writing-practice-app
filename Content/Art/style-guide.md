# ことばの絵の描き方（スタイルガイド）

ことばの絵（`Content/Art/words/`）を描くときの決まり。絵は `Scripts/art/words.py` で描く。
見本は kuma・inu・zou・ushi・kirin・neko の6つ。

## 1. 全体の決まり

### 形

- 色はベタ塗り。線はこげ茶（`#4a3428`）。影は1色だけ。白いつやを1つ入れる。背景は透明。
- 頭は大きく、体は小さく。頭の高さは全体の 4〜5 割（キリンのように首が長い動物は別）。
- 形は丸や四角の寄せ集めにしない。腰→もも→ひざ→足首→足先のように、体のつくりをなぞった1本の流れで描く。
- 輪郭は 2〜4 本の曲線で作る。点をたくさん打たない。
- 隠れる部分（脚・腕の付け根、首の付け根）も体の中まで描いておく。重ねたときにすき間が出ない。
- 顔はデフォルメしても、体の比率は本物から離しすぎない（キリンは首と脚が長い、ウシはがっしり、など）。何の動物か分からなくなる。

### 線（`Art.part()`）

- 塗りだけを描き、線は自動で付ける。線が出るのは「部品のいちばん外側」だけ。
- 同じ部品の中の形どうしの境目には線を出さない（体と手前の脚、頭と同じ色の耳）。
- 手前の部品が奥の部品に重なる所は、部品を分ける。手前の部品の線が出る（頭と体、体と奥の脚）。
- 部品の中に線が要るときは、先が細くなる線（`Art.ink()`）を少しだけ入れる。ももの付け根、ひじ、しっぽの巻き など。
- 小さな形ごとに線で囲まない。「部品を貼り合わせた絵」に見える。

### 顔

- 体が横向きでも、**顔は見る人の方に向ける**。両目・両耳・両ほほを左右対称に描く。
- **目は左右同じ大きさ**。顔の真ん中より少し下に置き、間を広くあける（目と目の間は、目の幅の2つ分以上）。
- 目はこげ茶のたて長の丸。白い光を右上に大きく1つ、左下に小さく1つ。
- 鼻と口は小さく、目の間の下にまとめる。ほほのピンクは目の外側の下。
- 鼻先の明るい色（マズル）は線で囲まない。塗りだけにする。
- 耳は必ず2つ見せる。角も2つ。

### 脚と足先

- 脚は上が太く、下へ細くなる。まっすぐな棒にしない。後ろ脚は「ひざが前、かかとが後ろ」に曲げる。
- 奥の脚は影の色にして、手前の脚の内側に少しずらす。4本が重ならないように間をあける。
- 足先は丸い終わりにする。指の切れ込みは**2本まで**（`toes()`）。入れなくてもよい。
- ひづめは脚の下を別の色にするだけ。線で区切らない（`hoofed()`）。
- 足の裏を見せるときは、肉球は大きな丸を1つだけ。
- 足は全部、同じ地面の線に置く（`GROUND` と `Art.ground_params`）。まちで下ぞろえにするため。

### やらないこと（不気味に見える）

- 左右で大きさのちがう目（ななめ向きの顔の遠い目を小さくする描き方）。
- 片方の耳や片方の目が隠れた顔。半分隠れた顔。
- かわいい頭に本物らしい遠近をつけること。
- 指を3本より多く描く。小さな丸をいくつも並べた足先。
- 丸や角丸の四角をそのまま貼り合わせた脚。
- 全部の形を線で囲むこと。
- 細かい毛・しわ・筋肉の線。模様は 3〜6 個の大きな形にする。

### 確かめ方

- `Scripts/art/run.sh <名前>` で 512px と 120px を出す。両方で見る（まちでは 120px くらい）。
- 120px で、何の動物か・顔がどこか・脚が何本かが分かること。
- 「子ども向けの絵本やシールの絵のとなりに置けるか」で判断する。だめなら直す。

## 2. 動物ごとの決まり

### くま（kuma）

- 正面を向いてすわる、ぬいぐるみの形。頭は全体の 4 割強。
- 耳は頭の上の両はしに丸く。頭と同じ部品にして線を出さない。
- 鼻先は明るい色の横長の丸。鼻は逆三角、口は「ω」。
- 足は前に投げ出し、足の裏を見せる。肉球は大きな丸1つ。
- 肩は丸く、体の輪郭とひと続きにする。左右の肩が同じ高さ・同じ丸みに見えること。
- 腕は肩の丸みの中から生やす（付け根を体の中まで描く）。片手を上げてふり、先は丸い手。もう片方は体の横に下ろす。わきの線は先細りの短い線だけ。

### いぬ（inu）

- 体は横向き、顔は正面。たれ耳を顔の両側に（耳は顔より濃い色）。
- 鼻先は明るい色。鼻は大きめに描く。小さな舌を出してよい。
- 脚は4本。手前の2本は体と同じ部品。後ろ脚はかかとを後ろに出す。足先は丸く、指は2本。
- しっぽは上に向けて元気に。首輪。

### ぞう（zou）

- 体は横向き、顔は正面。**大きな耳を両側に2つ**（内側はピンク）。
- 鼻は顔の真ん中から下へ。先を丸く巻く。付け根は顔とつなげて線を出さない。しわは 2〜3 本。
- 目は鼻の付け根の両側に、小さめ・同じ大きさで。
- 脚は太い柱。少しだけ下を細くする。つめは描かない。
- しっぽは細く、先にふさ。

### うし（ushi）

- 体は横向きでがっしり。背中はまっすぐ、おなかは深い。顔は正面。
- 顔の下半分はピンクの大きな鼻先。鼻の穴はたて長の丸2つ。口は小さく。
- 耳は横にねかせて2つ。角は耳の内側の上に2つ。
- 黒い模様は目にかけない（目が見えなくなる）。体に 2〜3 個、顔のはしに1個。
- 脚は太め。下はひづめの色。おなかの下にピンクの乳。首にベル。

### きりん（kirin）

- 体は横向きで小さめ。首は長く、付け根を太く。脚は長く、ひざをふくらませる。
- 4本の脚は前後に開く。束にしない。
- 顔は正面。たて長の丸で、下に明るい鼻先。角は丸い先の棒を2本。耳は横に2つ。
- 首の後ろに茶色のたてがみ（体の奥の部品）。模様は角ばった丸を大小まぜて。

### ねこ（neko）

- すわった形。顔は正面。三角の耳を2つ（頭と同じ部品）。
- 鼻は小さな逆三角、口は「ω」。ひげは左右に2本ずつ。
- 前脚は胸の前に2本、横にならべてまっすぐ下ろす。脚は太く（1本が頭の幅の 1/4 くらい）、線ではなく面で見せる。
- 足先は地面の上の大きな丸。クリーム色の「くつした」にして体と色を分ける。指は2本まで。
- 後ろ脚は、ももを1つの丸いかたまりにして後ろに置く。その前の地面に、後ろ足の先を前足と同じくらいの丸い足先（クリーム色）で見せる。
- しっぽは後ろから回して、ももの前の地面に置く。しま模様は帯で。
- 120px で「前脚2本・後ろ足・しっぽ」が見分けられること。

## 3. 描き方（`part()`・`sil()`・`ink()`）

`Scripts/art/words.py` に `@word` を付けた関数を書く。関数の名前がファイル名になる。`Art` を作って返す。

1. **奥から手前へ、部品ごとに描く。** 奥の脚 → 体（手前の脚・しっぽも同じ部品）→ 首輪など → 耳 → 頭 → 顔のパーツ。
2. **部品は `with a.part():` で囲む。** 中で `a.sil(パス, 色)`（だ円は `a.sil_ellipse`）を足す。線は部品の外側に自動で付く。
   - つなげたい形は同じ部品に入れる（体と手前の脚、頭と同じ色の耳）。
   - 境目に線がほしい形は、別の部品にして後から描く（体の上の頭、頭の上のたれ耳）。
   - `part()` の外で `a.sil()` を呼ぶと、その形だけの部品になる。
3. **線のない塗りは `a.blob(パス, 色)`。** おなかの影、模様、鼻先の明るい色、耳の内側。部品の形の内側におさめる。
4. **部品の中の線は `a.ink([(x0,y0, x1,y1, x2,y2, x3,y3)], 太さ, a=, b=)`。** 三次ベジェの線が、先の細い塗りになる。`a`・`b` は両はしの太さ（1 = 輪郭から出る側、0 = 消える側）。ももの付け根・ひじ・わきだけに使う。
5. **顔**は `a.eye(x, y, r)` を左右同じ `r` で、`a.cheek()`、口は `a.path(..., sw=7)`、つやは `a.shine()`。左右対称の形は `sym(a, パス, 色, cx)`。
6. **よく使う形**：`limb_d(関節, 太さ, 地面)`（脚。最初の関節は体の中に置く）、`taper(ベジェ, 太さ0, 太さ1)`（しっぽ・鼻・腕・首）、`hoofed()`（ひづめの脚）、`toes()`（指2本）、`band()`（しま）。
7. 足を地面にそろえる絵は、名前を `GROUND` に入れる。
8. `Scripts/art/run.sh 名前` で作り、512px と 120px を見て直す。古い描き方（`a.path(..., fill=)` で形ごとに線を付ける、`Art.leg`、`join`）は新しい絵では使わない。

例（いぬ。体の部分と頭の部分）：

```python
@word
def inu():
    a = Art()
    TAN, TAN_D, EAR = "#f2c48d", "#d9a56c", "#b8794a"
    G = 450                                   # 地面
    with a.part():                            # 奥の脚（影の色）
        a.sil(limb_d([(300, 330), (306, 388), (310, 434)], [50, 38, 30], G, foot=10, h=18), TAN_D)
        a.sil(limb_d([(396, 330), (382, 374), (400, 408), (396, 434)], [48, 38, 28, 27], G, foot=10, h=18), TAN_D)
    with a.part():                            # 体・しっぽ・手前の脚は1つの部品（継ぎ目なし）
        a.sil(taper([(452, 290, 500, 292, 522, 262, 524, 220)], 36, 22), TAN)
        a.sil("M214 262 C260 228 380 224 436 246 C482 264 490 324 462 358 C440 382 380 374 330 378 "
              "C280 382 236 392 212 356 C196 326 198 284 214 262 Z", TAN)
        a.sil(limb_d([(246, 300), (246, 384), (244, 432)], [76, 46, 36], G, foot=12, h=20), TAN)
        a.sil(limb_d([(438, 300), (428, 366), (450, 406), (446, 432)], [96, 58, 34, 32], G, foot=14, h=20), TAN)
        a.blob("M290 378 C330 380 380 378 404 376 C398 366 396 360 396 352 C360 362 320 362 290 358 Z", TAN_D)  # おなかの影
        a.ink([(402, 384, 392, 352, 400, 316, 430, 294)], 9, a=1, b=0)   # ももの付け根
        a.ink([(274, 386, 282, 362, 280, 340, 270, 320)], 8, a=1, b=0)   # ひじ
        toes(a, 226, G)
    cx = 190                                  # 顔の真ん中
    a.sil("M190 104 C254 104 286 146 286 196 C286 252 244 286 190 286 C136 286 94 252 94 196 "
          "C94 146 126 104 190 104 Z", TAN)   # 頭（体の上に線が出る）
    a.ellipse(cx, 238, 46, 36, CREAM, sw=0, stroke="none")               # 鼻先は線なし
    with a.part():                            # たれ耳は頭の上の別の部品
        sym(a, "M136 116 C100 100 62 124 62 176 C62 218 86 242 106 228 C122 214 116 168 144 138 Z", EAR, cx)
    a.eye(cx - 44, 192, 17)                   # 目は左右同じ大きさ
    a.eye(cx + 44, 192, 17)
    a.cheek(cx - 68, 230, 16, 10)
    a.cheek(cx + 68, 230, 16, 10)
    return a
```

## 4. 全部のことばを描いて分かった決まり

130語を描き直したときに分かったことをまとめる。1〜3 の決まりに足して使う。

### 形と部品
- 物・のりもの・たてものは、本体を1つの部品（1本の輪郭）にする。帯・影・ドアは `blob` で中に塗る。窓は細い線の部品（`part(5〜6)`）で囲む。
- 小さな部品（ライト・取っ手・はしご・ひも）は線を細くする（`part(6〜8)`）。太さ 11 のままだと黒いかたまりになる。
- 細い棒を並べる絵（はしご・スポーク・線路）は、棒のあいだのすき間を 10px 以上にする。
- 重なって見せたい物（花びら・ざりがにの節・くつの左右）は、層ごとに部品を分ける。同じ部品だと間の線が消える。
- 同じ物が集まる絵（ぶどう・花びら・草）は、外の線を1本にする。中の区切りは、手前が奥に重なる所だけ先細りの線にする。
- 雲は、こぶが出会う所をくぼませた1本の輪郭と、くぼみから入る先細りの短い線で描く。丸を並べない。
- もこもこ（ひつじの毛・うさぎのしっぽ）は、だ円に沿ったこぶを1本のパスで描く。
- 髪・たてがみは、毛先のとがった房を2〜3個つなげる。1つのかたまりにしない。
- 巻いた形は、内側の半径が 30px 取れないなら巻かずに反らせる。
- 輪（タイヤ）は、外の丸と逆回りの内の丸を1つのパスにする。

### 塗りと影
- 影は1色だけ、右側と下側に。ふちの内側の三日月にすると形からはみ出さない（はみ出すと自動の線を隠す）。
- 輪郭にぴったり沿う塗りは、輪郭のベジェを切り出して作る。
- `A`（円弧）は使わない。大きさ合わせの計算に入らない。丸もベジェで描く。
- 2色にまたがる影は、半透明の塗りを1枚かぶせる。
- 白い物（雲・雪・いか）は白いつやが見えないので、底にうすい水色の影を入れる。
- 緑の体の上のほほは、透けない色（`#f3b3a4`）にする。半透明だとにごる。
- 食べ物・植物の中の線は、その物の濃い色でよい。こげ茶の線は、ふちから入るしわだけにする。

### 生きもの
- 頭と体の色が同じか近い虫は、頭と体を1つの部品にし、しまや色の境目で分ける。
- 真横で描く魚（さかな・めだか・いるか）は目が1つでよい。丸い体のもの（くじら・たこ・くらげ）は正面の顔（両目）。
- 黒っぽい体は、目の後ろに白いだ円を置き、口は白い線にする。
- 脚の多い生きもの（たこ・かに・いか）は、奥の脚を影の色の部品、手前の脚を体と同じ部品にする。
- 奥の脚は、地面の所で手前の脚から 40px 以上はなす。近いと小さい絵で束に見える。
- おなかの明るい色は、脚の間いっぱいに塗らない（四角に見える）。おなかの線に沿った細い帯にする。
- 白い動物の前脚は、上が丸い短い脚を別部品にして体に重ねる。
- 腕を体に重ねるときは、付け根を頭の下（隠れる所）から始め、体のふちに沿わせて手をひざやおなかに置く。
- 首のある動物（うま・しか・らくだ）も、頭は見本と同じくらい大きくする。
- こげ茶の足の裏に明るい丸を入れない（車輪に見える）。

### へんしん・おしごと（着る ひとそろい。D178）
- 人は描かない。上に かぶる物、下に ふくを置いた ひとそろいにする。かぶる物と ふくは、少しだけ重ねる。
- ふくは `h_top()`（長そでを広げた形）をもとにして、色・えり・おび・ベルトで分ける。おびは `h_band()`・`h_sleeve_band()`。
- その人だと分かる しるしを 1〜2個 大きく入れる（星・十字・いかり・ちょうしんき）。武器は描かない。
- 似た組（だいく と しょうぼうし、にんじゃ と おまわりさん）は、かぶる物の形と ふくの色を はっきり変える。

### からだのことば
- 頭のない胴体だけは描かない。全身の子どもにして、その部分を手・つや・しぐさで目立たせる。
- 口は、くちびるを厚く・つやつやにすると大人に見える。細いふちと歯の帯1つ、小さな舌にする。
- 人の手足の指は5本でよい（「切れ込みは2本まで」は動物の足先の決まり）。ただし1つの輪郭にまとめる。

### いえの なかの物（D185）
- 顔はつけない。本体を1つの部品にして、ふた・取っ手・引き出しは別の部品で重ねる。
- たなの物（なべ・おわん・おさら・やかん など）は、少し上から見た形にする。口や ふちを だ円で見せ、底は平らにする。
- ゆかの物（いす・つくえ・たんす・ふとん）は、正面か 少しななめから見て、脚の下を絵の下にそろえる。奥の脚は影の色にする。
- かべの物（とけい・かがみ）は真正面。とけいの針は 10時10分、短い針を太くする。かがみは水色に白いななめの線を2〜3本。
- 細い物（はし・くし・はぶらし）は、ななめに置くか太めに描いて、ます目をうめる。くしの歯は線を細くして（`part(9)`）、すき間を 10px 以上あける。
- おもちゃばこ（`Content/Art/parts/omochabako.svg`）は ことばではなく へやの部品。`words.py` の `omochabako()` で作る。

### 季節の飾り（D188）
- つるす物（うちわ・ふうりん・ちょうちん・てるてるぼうず・ちとせあめ）は、絵のいちばん上を「つるす所」（ひも・輪）にして、左右の真ん中に置く。アプリは絵の上のはしを支点にして ゆらす。
- 立てる物（こいのぼり・ゆきだるま・かどまつ など）は、下を平らにして、絵の下のはしを足もとにする。
- 空の物（はなび）は、まん中から外へ広がる形にする。昼の空でも見えるよう、光の すじにも線を付ける。
- 行事の飾りは色が多くなるので、1枚の色は 4〜5色まで。赤・白・金・緑を中心にする。

### アプリとの合わせ
- アプリが上に丸を重ねる所（しんごう・ふみきりのあかり）には、つやや ひさしを重ねない。位置を変えたら `LampMotion.swift` の数も直す。
- ぶらんこ・すべりだいの動きの数（`PlayMotion.swift`）は、絵に合わせて直す。
- 描いたら `Scripts/art/sync_assets.sh <名前>` でアプリの絵に写す。

## 5. 主人公（とん・るん・ひら）

`Scripts/art/chars.py` で描く（D177）。ことばの絵と同じ決まりに、次を足す。

- 体と腕は1つの部品。腕は体の中の肩から生やし、先の丸みを手にする。足は体の奥の、小さな丸い足。
- 目は左右同じ大きさ。happy は「＾＾」、sleep と blink は下向きの弧。blink は normal と体が同じ。
- 色としるしは変えない: とん（赤だいだい・しずく・ひたいの点）、るん（空いろ・はねたアンテナ）、ひら（わかばいろ・しっぽ・金色の葉）。
- 1人の5ポーズは同じ倍率・同じ位置（`fit`）。体の真ん中は x = 256、足の下は y = 488。きらきら・zzz・手を振る線は、その枠の中に置く。
- 描いたら `Content/Art/characters/` の SVG を `Assets.xcassets` の `char-<名前>-<ポーズ>.imageset` に写し、`sheetchars.swift` で一覧を作り直す。
