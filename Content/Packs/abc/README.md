# アルファベットと数字のデータ（D180）

大文字 A〜Z、小文字 a〜z、数字 0〜9 の62字。ID は `abc.<字の番号（16進）>`（例: a は `abc.61`）。

## 作り方

- 形は `Scripts/make_abc.py` の中に、線と円弧で書いてある。フォントはなぞっていない（D127 の Andika は使わない）。
- 作り直す: `python3 -I Scripts/make_abc.py Content/Packs/abc`（Mac だけ。輪郭を `Scripts/abc_outline.swift` で作る）。
- 一覧を見る: `swift Scripts/abc_sheet.swift Content/Packs/abc <出力.png>`（灰色がお手本、赤が中心線、丸の数字が書き始めと順）。
- 形を直したら、字の `rev`（`make_abc.py` の `REV`）を上げる（D114）。
- `pack.json` は手で書く（パックの情報。D106）。

## 形の決まり

- 日本の小学校の英語の教科書の手書きの形に合わせる。a と g は1階建て。小文字は「棒と丸」。I は上下に横線を付ける（l・1 と見分ける）。
- アルファベットは4本の線に合わせる（マス 0〜1000。y は下向き）。

| 線 | 高さ | 使う字 |
|---|---|---|
| 上の線 | 70 | 大文字の上、b・d・f・h・k・l の上 |
| 中の線 | 340 | 小文字の丸の上。i・j の点は 205、t の上は 160 |
| 基本の線 | 660 | 字の下 |
| 下の線 | 930 | g・j・p・q・y の下 |

- 数字は算数の教科書の形。140〜860 の高さで、マスのまん中に書く。4 は上があいた形、7 は1画、1 は棒だけ。
- お手本の輪郭は、中心線を同じ太さ（アルファベット 54、数字 60）で太らせたもの。
- 画の終わり方は、すべて「とめ」。
- i・j の点は、長さのない画（どの向きに書いても合格にするため）。

## 書き順と画数（D66）

アルファベットと数字の書き順は、国の決まりがなく、教科書会社でちがう。
お手本には、日本の教科書やペンマンシップでよく見る書き方を1つ見せる。判定は、下の「ほかの正解」も合格にする。
`orders` は同じ画の別の順、`alternates` は画数や画の分け方がちがう書き方。

**この表は、記憶をもとに作った。人が、教科書会社2社以上の資料と照らして確かめること（D66）。**

## 鏡の字（D107）

左右対称に近い字（A H I M O T U V W X Y、i l o v w x、0 1 8）は、鏡の字を見ない（`mirrorCheck: false`）。
b・d・p・q などは見る。

## 人が確かめること

- 62字の形と書き順・画数（上の表）。とくに E・G・I・K・M・Y、k・t・y、4・5・7・9。
- 7 を2画（左上に短い縦）で教える教科書があれば、お手本を入れ替えるか決める。
- 子どもに試してもらい、判定がきびしすぎないか（小文字の「もどり書き」、点）。
