# 効果音の波形の調べ（2026-11-17）

25 個の効果音（`App/Mojimachi/Resources/Sounds/*.caf`）を、**耳ではなく波形から**調べた。かわいい・安全かを見積もり、替えたほうがよい音に印を付ける。

**これは耳の代わりにならない。最後は人が全部聞いて決める。** この調べは「怪しい音を先に見つける」ためのもの。

## 方法

- 道具: `Scripts/analyze_sfx.py`（numpy / scipy / matplotlib。開発用。アプリには入らない。`docs/dependencies.md`）。
- `afconvert` で 48kHz モノラル WAV にしてから測る。
- 基準（かわいい側の目安）: SoundKit の `Tones.swift` と同じ式で作った音（`ref_stroke_do`・`ref_stroke_so`・`ref_praise`・`ref_tap`）。同じ式を Python で書き直して作った。
- 測るもの: 長さ、ピーク、アクティブ音量（最大から 40dB 以内の RMS）、立ち上がり（10%→90%）、余韻（ピークから -40dB まで）、スペクトルの重心、150Hz・300Hz 未満のエネルギー比、基本周波数（YIN）、平坦度（ノイズっぽさ）、ざらつき（包絡線の 20〜150Hz の揺れ）、クレスト、割れ。
- スコア（0〜100）は透明な経験則。重み: 高さ 20、明るさ 15、まとまり（平坦度が低い）15、短さ 10、立ち上がり 10、低音の少なさ 10、なめらかな終わり 5、ざらつき 5、割れなし 5、音量がそろう 5。式の詳細はスクリプトの冒頭に書いてある。
- 「要確認」の印: `LOW`（150Hz 未満 10% 超 または 300Hz 未満 35% 超）、`NOISY`（平坦度 0.25 超）、`ROUGH`（揺れが強い）、`ABRUPT`（立ち上がり 1ms 未満で大きい。短い UI 音は除く）、`TAIL`（余韻 1.2 秒以上）、`GROWL`（基本周波数 250Hz 未満で 0.4 秒以上）、`LOUD`/`QUIET`（中央値 -18.5dB から ±4dB 超）、`CLIP`。
- 図: 波形とスペクトログラムの PNG。全部を並べた一覧。LOOK して、数値と食い違わないか確かめた（下の「図の確認」）。

## 要確認の音と理由

重い順。

1. **word_fune（ふね）** 替える。基本周波数 151Hz の一定の低い響き（船の汽笛）。300Hz 未満が 98%、アクティブ音量は中央値より 8dB 大きく、余韻も 1.25 秒。スペクトログラムでも最下部に 1 本の太い帯だけ。低くて大きく長い「ボーッ」は、小さい子には怖く聞こえるおそれがある。
2. **word_ushi（うし）** 低くて大きい。基本周波数 274Hz、300Hz 未満が 86%、中央値より 4.6dB 大きく、1.8 秒で最も長い。うしの「モー」としては自然。替えるより、短く（1.0〜1.2 秒）して音量を 4〜5dB 下げるか、高めの子牛の声に替えるのが現実的。
3. **word_yukata（ゆかた）** 替える。ふとんを動かす音で、ノイズ（平坦度 0.25）、150Hz 未満が 28%（こもったゴソゴソ）、かなり小さい（-29.5dB）。かわいくもない。
4. **word_kutsu（くつ）** 150Hz 未満が 82%（ドスッという床の音）。重心 189Hz。怖くはないが、重くてこもった音。替える候補。
5. **word_kutsushita（くつした）** 150Hz 未満 30%。短く 0.27 秒で、布の音。低めのカサカサ。弱い候補。
6. **word_fuku（ふく）・word_boushi（ぼうし）** ノイズ（平坦度 0.37・0.41）。衣ずれ・ヘッドバンドの音で、ほぼノイズの「シャッ」。怖くはないが、音としてのかわいさは低い（スコア 56・63）。ふく（アクティブ -32.4dB）はほとんど聞こえない。
7. **confetti（クラッカー）** ノイズ（平坦度 0.25）、重心 5.1kHz、立ち上がり 2ms、ピークに対してアクティブが小さい（クレスト 25.8dB）。つまり「パン」と鳴る瞬間が鋭い。小さい子がびっくりする可能性がある。音量そろえで +3.5dB の案が出ているが、上げずに据え置き、聞いて決める。
8. **locked（ぼよん）** ざらつき 0.62（ボヨンの揺れ。意図どおり）。見た目の ROUGH は意図的な揺れと考えられるので、実際に聞いて決める。
9. **sparkle** 余韻 1.52 秒（長め）。きらきらの尾で、怖くはない。ゲームの合図としては少し長いだけ。短く切ってもよい。
10. **word_shika（しか）** 印は付かなかったが、波形（`word_shika.png`）は、最初の長い声のあとに短い 5 回の「ケッ」。犬の吠え声や警戒の声に聞こえる可能性がある。数値では判断できないので、聞いて確かめる。
11. **word_densha（でんしゃ）・word_risu（りす）** 中央値より 4dB 大きい（LOUD）。音の質は問題なし。音量を下げるだけ。

## 替える候補と、探すときの特徴

| 替える | 欲しい音 | 探す言葉の例 |
|---|---|---|
| word_fune | 高めで短い汽笛。400〜1000Hz が中心。0.8 秒前後。ポーッ と小さく | `toy boat whistle`, `small ship horn short`, `ferry whistle high`, `tugboat toot`, `汽笛 短い` |
| word_ushi | 子牛や明るい声のモー。1 秒前後。声が高く、立ち上がりがやわらかい | `calf moo`, `cute cow moo`, `cartoon cow`, `牛 鳴き声 子牛` |
| word_yukata | 低音のないやわらかい布の音。または短い鈴・衣ずれ | `soft cloth swish short`, `fabric rustle light`, `kimono sleeve`, `着物 衣ずれ` |
| word_kutsu | 床にコトッと置く軽い音。重心 800Hz 以上、低音なし。0.3 秒 | `light footstep tap`, `wooden block tap`, `shoe tap soft`, `靴音 軽い` |

共通の条件: 重心が 700Hz 以上、300Hz 未満のエネルギー 5% 以下、1.0〜1.5 秒以内、立ち上がり 5〜50ms、終わりはなめらかに消える。

## 音量そろえの案

- 中央値のアクティブ音量は -18.5dB。上の「音量案」の列のとおり、中央値に寄せる。
- 大きく下げる: word_fune（-8.1）、word_ushi（-4.6）、word_densha と word_risu（-4.1）。
- 大きく上げる: word_yukata（+8.2）、tap（+7.2）、word_kutsu（+5.0）、word_kutsushita（+4.8）、gather（+3.6）、confetti（+3.5）。ピークの余裕（-1dBFS まで）の中に収めてある。
- 音量を変えるのは `Scripts/process_sfx.py` のピーク目標（今は -3〜-8dBFS）でするのが筋。このタスクでは音源もコードも触っていない。
- 「平均を中央値に寄せる」だけでは、短い音（タップ）とずっと鳴る音（ふね・うし）の聞こえ方の差は消えない。最後は耳で調整する。

## 限界

- 音の中身（何の音か、声がかわいいか、怖い感じがあるか）は数値では分からない。特に動物の声（しか・うま・くま・いぬ）は、聞くまで判断できない。
- 基本周波数が取れない音が多い（ノイズ・高い声）。その音の「高さ」は重心で代わりに見ている。
- スコアの重みと印のしきい値は、基準の音と 25 個の分布を見て決めた目安で、研究で確かめたものではない。
