# 言葉づかいの手引き（D150）

子どもの画面の言葉は、アプリの人柄の一部。「また書きたい」と思える言葉にする。新しい言葉はこの手引きに合わせる。

## 基本

- ひらがなで、短く書く。1つの言葉は多くても10文字くらい。
- 「がんばろう」より先に「たのしく」を置く。
- 間違いを責めない。次にすることを短く言う。
- 数字や点数で比べない。ほかの子とも比べない。
- 子どもの画面に、エラー・価格・購入は出さない（D3・D117）。

## 使う言葉・使わない言葉

| 場面 | 使う | 使わない |
|---|---|---|
| はじまり | 「たのしく かこうね！」「いっしょに かこう」 | 「がんばろう！」「れんしゅうしなさい」 |
| 書き始めの案内 | 「ここから かいてみよう」「よく みてね」 | 「ちがうよ」「そこじゃない」 |
| 合わなかったとき | 「もういちど かいてみよう」「ここから かいてみよう」 | 「ちがう」「だめ」「まちがい」「しっぱい」「ざんねん」 |
| できたとき | 「いいね！」「すごい！」「かんぺき！」「じょうずに かけたね！」 | 「やっと できたね」「ふつう」 |
| 鍵のかかった字 | 「おとなのひとに おねがいしてね」 | 「かえません」「ロックされています」「ざんねん」 |
| 待つとき | 「もうすぐ あそべるよ」 | 「エラー」「しばらくおまちください」 |

## ほめ言葉（D152）

| ほめ方 | 星 | ほめ言葉 |
|---|---|---|
| まる | 1つ | 「いいね！」 |
| にじゅうまる | 2つ | 「すごい！」 |
| はなまる | 3つ | 「かんぺき！」 |

## 育ちの名前（D151）

字は「たね → め → つぼみ → はな」と育つ。文字の種類は「ふたば → つぼみ → はなばたけ」。うまくいっていない字にも「まだ」「だめ」と言わず、「たね」と呼ぶ（これから育つもの）。

## キャラクターのせりふ（§3.9）

- 呼びかけの言葉（「きみ」など）は使わない。全体への呼びかけは「みんな」。
- 例: 「わあ、じょうずに かけたね！」「なにが すき？」。
- 呼び名は画面にだけ出す（「ゆうとくん、すごい！」）。声では読まない。
- 長い説明をしない。1回に1つのことだけ言う。

## 保護者用の画面

保護者用の画面は漢字まじりの、ふつうの丁寧な言葉でよい。ただし責める言い方はしない（例:「確認できませんでした」ではなく「もういちど どうぞ」のように次にすることを言う）。学習記録には、これまでの言い方（「なぞって かけた」など）を残し、育ちの名前を「（つぼみ）」のように添える。
