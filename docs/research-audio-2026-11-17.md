## 1. 日本語の声

### 必要な量の見積もり

- キャラのせりふ: 約450本。1本 約25文字で約1.1万文字。
- えほんの こえ: 約2,000本。1本 約30文字で約6万文字。
- やり直しを4倍とみて、合計およそ40万文字。

### 推し

- 第一候補は ElevenLabs。理由は、日本語の表現力、文章から声を作れること、感情を指定できること、値段が安いこと。
- キャラ3人は Voice Design で子どもが親しめる声を作り、同じ声の ID をずっと使う。声のぶれは、同じ文でも出るので、本数に余裕を見て選ぶ。
- 「えほんの こえ」は落ち着いた大人の声。2,000本は一貫性が大事なので、声と設定を固定して一括で作る。
- 読みの間違いが出やすい。せりふは**ひらがなで書いて**送る（D75 の読みの照合と合わせる）。人の最後の聞き取り確認は必須。
- 次の候補は Chirp 3 HD。ElevenLabs の質が足りないとき、または規約で止まったときに使う。

### 英語の声

- 日本語と同じ ElevenLabs で、英語の声を1つ作る（D57）。アルファベットは文字の名前で読む（D29）。
- 次の候補は Chirp 3 HD の英語の声。

| AIVA / Soundraw / Mubert / Udio | **今回は調べていない** | | |

### 推し

- 第一候補は Suno Pro。アプリや遊びを特に制限していない。月 $10 で15曲に十分なクレジット。
- 次の候補は ElevenLabs Music。アプリに使えるかを**契約前に ElevenLabs に問い合わせて、返事を保存する**。教育アプリは「ゲーム」に当たらない可能性が高いが、規約からは断定できない。
- 約15曲は、書く画面は静かな曲（D115）。「楽器だけ」「ゆったり」などの指示を使い、1曲を5〜10回作って選ぶ。
- 繰り返し: どのサービスも完全なループは作れない。D115 の自動確認（つなぎ目）の前に、スクリプトでクロスフェードを入れる。
- 既存の曲に似ていないかの確認（D115）は、Suno でも必要。アーティスト名などをプロンプトに入れない。
- Suno には、音の出どころを示す透かし・メタデータを消してはいけない、という決まりがある。圧縮のときも注意する（Opus に変えると消える場合がある。**要確認**）。

## 3. 効果音（約100〜200個）

- 単純な音（ド→レ→ミ、ボタン、ほめる音）は、プログラムで作る（D115）。権利の心配がない。
- 鳴き声・物の音は ElevenLabs Sound Effects。公式は「ロイヤリティフリー」で、有料プランで商用可。値段は $0.12/分とされているが、公式 FAQ は「1回の生成ごと」とも書いていて**食い違い**がある。100個 × 3回のやり直しで多く見ても $50 ほど。
- 無料素材（次の候補）: Pixabay は商用可で、表示不要とされる（公式 FAQ は商用可のみ確認。表示の要否は第三者の情報）。音ファイルだけの再配布は禁止。OtoLogic は表示が必要とされるので、使うなら「このアプリについて」に載せる。効果音ラボ・Freesound などは今回は規約を確認できていない。
- 本物の動物の鳴き声は、AI が似ない場合がある。人の耳で確かめる。

## 4. 圧縮と名前（D62・D112）

- 声: Opus のモノラル、24〜32kbps。BGM: Opus のステレオ、64〜96kbps。効果音は声と同じ。
- 強さは M0 で聞き比べて決める。圧縮前の元データは GitHub のリリースに添付して保管する（D112）。
- ElevenLabs は出力形式がプランで決まる（高音質は上位のプラン。**確認が必要**）。元の音質は、Creator 以上の MP3 192kbps か、使える中で最高のものにする。

## 5. 人がやること / Claude ができること

### 人がやること（Claude にはできない）

1. ElevenLabs のアカウントを作り、有料プラン（Creator）を契約する。支払いと規約への同意。API キーを作る。
2. Suno のアカウントを作り、Pro を契約する。規約に同意する。
3. 契約前に最新の値段と規約を読む。特に ElevenLabs の Voice Library の追加規約、ElevenLabs Music の「Studio Games」、VOICEVOX を使う場合のキャラごとの規約。
4. 疑問があれば ElevenLabs のサポートに「子ども向けの有料教育アプリに音楽を入れてよいか」を問い合わせる。
5. キャラ3人・えほんの こえ・英語の声の聞き比べと決定。BGM の聞き比べと決定。最終の聞き取り確認（D62）。
6. API キーを安全に置く（リポジトリには入れない）。

### Claude ができること

- ElevenLabs API で、せりふ表（ID つき）から声を一括で作るスクリプト。ID に合わせたファイル名。やり直し・差分だけの再生成。
- ひらがなへの整形、読みの照合表との突き合わせ。
- 効果音の一括生成と、単純な音のプログラム生成。
- ffmpeg（libopus）による圧縮、音量そろえ、無音の切り取り、クロスフェードのループ作成、つなぎ目の自動確認。
- 出どころの記録（サービス名・日・プロンプト。D81・D115）と、「このアプリについて」の表示文の下書き。
- Suno にはスクリプトで使える公式 API が**確認できていない**。BGM は人が画面から作ってダウンロードする必要がある可能性が高い。ダウンロードしたファイルの整理と圧縮は Claude ができる。

## 6. 不確かなこと

- ElevenLabs の無料枠・プランごとの文字数（資料で食い違い）。
- ElevenLabs の日本語の質（子ども向けの声）は、実際に聞くまで分からない。M0 で3社に同じ10文を作らせて比べるとよい。
- OpenAI・Azure・Polly の商用条件の本文は読めていない。
- Suno の著作権の扱い（出力の権利の譲渡と、著作権が成立する保証がないこと）。
- AI 音声・音楽の法律や、サービスの規約は変わる。作った日の規約を保存しておく。
