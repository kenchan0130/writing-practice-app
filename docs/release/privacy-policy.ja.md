## 先に結論

- 広告はありません。
- 利用状況の分析や、追跡（トラッキング）はしません。

## iPad と iCloud に保存する情報

次の情報を、iPad の中に保存します。

- 呼び名（保護者が決めます。本名でなくてかまいません）、顔のイラスト、利き手、1日の目標の字数、ペンの色
- 練習の記録（書けた字、書いた日、判定の結果）
- 子どもが書いた線の形（字ごとに、はじめてと最近の数回分）
- 集めたもの、まちの配置、着せている服
- 子どもが鍵のかかった字で「おねがい」を押した記録
- 設定（判定の厳しさ、音量、字幕など）

iPad で iCloud にサインインしていて、保護者用の画面で「iCloud で同期」がオンのとき、上の記録を、保護者の iCloud の「非公開データベース」（CloudKit）にも保存します。

- これは保護者自身の Apple アカウントの保存場所です。運営者は中身を見られません。
- 目的は、アプリを入れ直したときや iPad を買い替えたときに、記録を戻すことです。同じ Apple アカウントの iPad どうしでも同期されます。
- 家族のあいだや、ほかの人との共有はしません。
- 「iCloud で同期」はいつでもオフにできます（保護者用の画面の「学習記録の管理」）。
- iCloud にサインインしていないときは、iPad の中だけに保存します。

## 外に送る情報

### クラッシュ報告（Sentry）

アプリが落ちたときだけ、クラッシュの情報を、クラッシュ報告のサービス Sentry（Functional Software, Inc.）に送ります。品質を直すために使います。

送るのは次のものだけです。

- 落ちた場所（プログラムのどこか）
- アプリの版
- iPadOS の版
- iPad の機種の大まかな種類

送らないものは次のとおりです。

- 呼び名や名前、練習の記録、子どもが書いた線
- 利用者や iPad を見分ける番号（ID）
- IP アドレス（保存しません）
- 操作の記録、画面の録画、使った時間の計測

この報告をオフにする設定はありません。落ちたとき以外は、何も送りません。保護者用の画面の「安心のための設定」にも、同じ説明があります。

送るクラッシュの情報は、保護者や子どもとは結びつけません。追跡や広告には使いません。

Sentry のデータの保管場所: 米国（United States）。保管する期間は、最長90日です。

### お問い合わせ

保護者用の画面から、お問い合わせのフォームを開けます。フォームは Google フォームで、Safari で開きます。調べるために、アプリの版と iPadOS の版をフォームに入れた状態で開きます。送るかどうかは、保護者が決めます。

- フォームに書いた本文と、任意のメールアドレスが、運営者に届きます。
- フォームには、最初から「アプリの名前」「お問い合わせの種類」「アプリの版」「iPadOS の版」が入っています。「この判定はおかしい」から開いたときは、判定の設定の名前も入ります。iPad の機種や端末の ID は入れません。送る前に、消すこともできます。
- フォームの扱いには、Google のプライバシーポリシーも適用されます。
- いただいた内容は、返事のためだけに使います。対応が終わってから90日以内に消します。削除のご依頼にも応じます。
- 子どもの名前や、子どもの写真は書かないでください。

### 購入

購入は Apple の App Store で行います。支払いの情報（カード番号など）は Apple が扱い、運営者には届きません。運営者は、どの商品が購入されたかをアプリの中で確かめるだけです（Apple の仕組み StoreKit を使います）。

## 子どもの情報について

このアプリは、5歳以下の子どもも使います。

- 子どもに、名前・住所・メールアドレス・電話番号・位置情報・写真・声を入力させません。そもそも入力する画面がありません。
- 子どもの画面には、外部へのリンク、購入、お問い合わせの画面を出しません。
- 外部へのリンク、購入、設定の変更、学習記録の閲覧は、保護者用の確認（かけ算の問題）を通ったあとだけできます。
- 呼び名は保護者が決め、iPad と保護者の iCloud の中だけに置きます。
- 米国の児童オンラインプライバシー保護法（COPPA）と、日本の個人情報保護法の考え方に沿って、子どもの個人情報を運営者が集めない作りにしています。

## このアプリが使わない iPad の機能

位置情報、カメラ、マイク、写真、連絡先、カレンダーは使いません。保護者用の確認で「iPad のパスコードも求める」をオンにしたときは、iPad の認証（Face ID・Touch ID・パスコード）を使います。顔や指紋のデータは iPad の中に残り、アプリや運営者には渡りません。

## 情報の消し方

| したいこと | 方法 |
|---|---|
| 1人の子の記録をすべて消す | 保護者用の画面 →「子どもたち」→ その子 →「削除」（赤いボタンを3秒長押し） |
| 1人の子の記録だけ消す（プロフィールは残す） | 同じ画面の「記録だけリセット」 |
| 全員の記録を消す | 保護者用の画面 →「学習記録の管理」→「全員の記録をリセット」 |
| iCloud にある記録を消す | 保護者用の画面 →「学習記録の管理」→「iCloud のデータを消す」（赤いボタンを3秒長押し）。ほかの iPad の記録も消えることがあります |
| アプリを削除したあとに iCloud の記録を消す | アプリを削除しても、iCloud の記録は残ります。iPad の「設定」→ 自分の名前 →「iCloud」→「ストレージを管理」→「もじまち」→「データを削除」 |
| お問い合わせで届いた内容を消す | 下のお問い合わせ先に、削除を希望するとお伝えください |

アプリを削除すると、iPad の中の記録は消えます。
